# The Amazing Spider-Man

## Overview
**The Amazing Spider-Man** is a *superhero film* based on the Marvel Comics character Spider-Man.

> “We all have secrets: the ones we keep... and the ones that are kept from us.”
---
## Main Characters
1. Peter Parker / Spider-Man
2. Gwen Stacy
3. Dr. Curt Connors / The Lizard
4. Uncle Ben
5. Aunt May

---
## Why I Love This Movie
- Great action sequences  
- Emotional storytelling  
- Strong chemistry between the main characters  
- Modern and stylish take on Spider-Man
